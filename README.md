## IEPL 和 IPLC 怎么选

IEPL 是二层以太网专线，带宽调整灵活，同档位通常更省钱；IPLC 是传统点对点专线，带宽完全独享，稳定性更硬。MKCloud 两条技术路线都有，区别主要落在使用场景上。

选法可以直接一点：日常访问国际服务、对延迟敏感，广港 IEPL 1–3ms 的内部延迟基本等于本地局域网的体验；业务在日本，或者中日之间要跑固定的数据链路，沪日 IPLC 更对口；美国方向只有沪美 IPLC，124ms 的延迟来自物理距离，换什么线路都省不掉。

## 第三方测评：延迟、硬件和 IP 质量

已公开的测评显示，这家店的延迟和带宽基本对得上标称值，但硬件和 IP 层面有几个细节要提前知道。

广港线（2023 年底测评，500GB 档）：香港出口跑在 AMD EPYC 7402P 上，磁盘 IO 平均 304MB/s；到香港本地节点单线程下载 131–135Mbps，接近 150Mbps 标称值；到台湾 26ms，到东京 52–57ms。路由为 UCloud 广州 BGP 进、Nearoute 香港出。

沪日线（2023 年 12 月测评）：Intel E5-2680 v4 平台，东京出口，到东京节点 25ms 出头，Cloudflare 测速 130Mbps，日本出口当时可解锁 Disney+、Netflix 和 ChatGPT。入口上海电信，出口日本 BGP（Nearoute）。

沪美线（2024 年 5 月测评）：出口落地西雅图，同样是 E5-2680 v4 平台。

两点提醒。第一，广港出口的 CPU 较新，沪日、沪美出口用的是老一代至强，跑远程桌面、开发测试没压力，但别指望拿它干重计算的活。第二，IP 质量在不同平台的结论不一致：香港出口 IP 属于 AS147293 Nearoute，IDC 机房属性，一个平台给的欺诈评分是 0/100，另一个给到 65/100——对 IP 纯净度有业务要求的，把这个变量算进决策里。另外，2023 年的广港、沪日测评都没有 IPv6，2024 年 5 月的沪日测评 IPv6 已在线，不同批次情况不一样，有需要的直接向客服确认。

## 下单前必须确认的四件事

限制条款比价格更值得花时间读，下面四条每一条都直接影响日常使用：

1. **实名认证**：需要用中国身份信息完成实名，绑定国内手机号。
2. **省级白名单**：部署时就要选定接入省份，同一时间只允许一个省份的 IP 接入；之后可以申请换省，但不能多省同时用。
3. **用途限制**：仅限合法的个人或商业用途，明确禁止代理、中转等不合规用途。
4. **退款条件**：只支持“确认存在质量问题”的退款，且需要提交延迟、测速数据作为证据；激活后不支持换购其他区域的产品。

> 一句话版本：这家的专线是给“固定地点、固定用途”设计的。常驻地固定、业务方向明确的人用着最顺；经常换城市、多地办公的，白名单机制会很别扭。
